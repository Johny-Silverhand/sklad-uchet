## Склад Учёт v1.2.0

Настоящее Windows-приложение с установщиком.

### Новое
- **Баланс** — постоянное хранение
- **Временное хранение** — отдельный раздел; перенос позиций ↔ баланс
- **Темы** — свои названия: создать / переименовать / удалить (позиции → «Без темы»)
- Фильтр и группировка по теме
- **WebView2** — своё окно «Склад Учёт» без адресной строки браузера
- Пустая БД при первом запуске (без демо-данных)
- CSV: поля `storage`, `theme`

### Установка
1. Скачайте **SkladUchet-Setup.exe**
2. Запустите мастер → ярлыки → «Установить»
3. Откройте «Склад Учёт» из меню Пуск / рабочего стола

Нужен Microsoft Edge WebView2 Runtime (обычно уже есть на Windows 10/11).
