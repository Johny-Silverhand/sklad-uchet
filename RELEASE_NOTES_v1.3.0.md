## Склад Учёт v1.3.0

Расширение раздела **Сервис**: печатные отчёты и инструменты склада.

### Новое
- **Печать отчёта** — все позиции или по теме / хранению / «только мало»; шапка с датой и «Разработано в Victimok Labs»; A4; открытие для PDF
- Быстрый **список «мало»**
- **Проверка целостности** БД (`PRAGMA integrity_check`) и **VACUUM**
- **Папка данных**: путь к БД, копирование, открытие в Проводнике (Windows)
- **Очистка журнала движений** с подтверждением
- Мини-статистика на странице Сервис
- Предупреждение о **ячейках с >1 позицией**
- Версия в «О программе» берётся из `/api/health`

### API
- `GET /api/report.html`
- `POST /api/db/integrity`, `POST /api/db/vacuum`
- `GET /api/paths`, `POST /api/reveal-data`
- `DELETE|POST /api/movements` (очистка)
- `GET /api/cells/crowded`

По-прежнему offline desktop, без демо-данных. **Victimok Labs.**
