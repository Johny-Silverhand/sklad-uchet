## Точка Склада v1.3.0

Склад под контролем — без браузера, без облака, без демо-мусора.

### Что изменилось
Приложение теперь называется **«Точка Склада»**: своя иконка, свои ярлыки, тот же надёжный локальный SQLite. База как была — `%APPDATA%\VictimokLabs\SkladUchet` — так что старые данные на месте.

### Сервис стал полезнее
- **Печать отчёта** — все позиции или одна тема, фильтр по хранению и «только мало», дата в шапке, A4, удобно сохранить в PDF
- Быстрый список **«Мало на складе»**
- **Проверка целостности** БД и **VACUUM** (подчистить и уплотнить)
- **Папка данных** — путь к БД, копирование, открыть в Проводнике
- **Очистка журнала движений** (с подтверждением)
- Мини-статистика прямо в «Сервисе»
- Подсказка по **ячейкам с несколькими позициями**

### Установка
Скачайте **`TochkaSklada-Setup.exe`**, установите, запускайте ярлык «Точка Склада».

Нужен WebView2 Runtime (обычно уже есть с Edge).
