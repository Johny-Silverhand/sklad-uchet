CSV экспорт / импорт

Файл UTF-8 с разделителем «;» (Excel в России). Колонки: id, name, kind, quantity, min_qty, cell, sku, notes, storage, theme. При импорте совпадения по id или названию+ячейке обновляются; новые темы создаются автоматически. Сделайте backup перед большим импортом.

Экспорт CSV

Резервная копия БД

Копия файла SQLite. Пустое поле пути = автосохранение в папку backups рядом с базой. Восстановление заменяет текущую БД (предыдущая сохранится как .before-restore). Не закрывайте программу во время операции.

Обслуживание БД

Проверка целостности SQLite и сжатие файла (VACUUM).
